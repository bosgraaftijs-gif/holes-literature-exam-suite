# Holes Exam Study Suite — Louis Sachar Literature Prep 🏜️

An offline, privacy-first, specialized English Literature study platform built specifically for mastering **Holes** by Louis Sachar for GCSE, IGCSE, AQA, Edexcel, and IB exams.

## Key Features & Literature Exam Modules
- 📂 **Collapsible Reference Drawer:** Collapsible sidebar for source documents, keeping student focus on core exam preparation tools.
- 🎯 **Study & Exam Hub:**
  - ⏳ **F1 Triple-Timeline Scrubber & Convergence Engine:** Triple-narrative chronological matrix (Latvia 1880s, Old Green Lake 1888–1890s, Camp Green Lake 1990s) with 6 structural convergence nodes and AO2 exam commentary.
  - 🧅 **F2 Symbolism & Motifs Explorer:** In-depth breakdowns of Yellow-Spotted Lizards, Wild Onions, Sploosh, Shovels/Holes, and The Lullaby with full model PEEL paragraphs.
  - 💬 **F3 Iconic Quote Challenge:** Curated quote test bank with 4-way speaker recognition, subtextual analysis, streak counter, and model essay application sentences.
  - 📝 **F4 Essay Prompt & Thesis Generator:** 5 standard exam prompts with an interactive 3-clause thesis statement builder and 3-paragraph PEEL outlines.
  - 🧠 **F5 SM-2 Spaced Repetition Flashcards:** SuperMemo SM-2 algorithmic Leitner intervals and 4-tier self-assessment with persistent local storage.
  - ⛏️ **F6 "Dig a Hole" Focus Timer:** 25-minute Pomodoro study sprint with real-time 5-foot shovel depth animation, hole counter, and water breaks.
  - 🕸️ **F8 Character Dynasty Network Graph:** Interactive SVG relationship tree spanning the Yelnats, Zeroni, and Walker dynasties with 16 characters and era filters.
  - 🎧 **2-Host Audio Deep Dive:** Conversational dialogue between hosts **Leo & Maya** analyzing novel themes via native Web Speech API.
  - 💬 **Literature Q&A:** Grounded exam assistant providing textually verified answers with clickable citations `[1]`, `[2]`.
- 📥 **Modal Ingestion & Conversion:** Convert novel notes, study guides, or past papers (PDF, DOCX, TXT, HTML, images) into clean `.md` or `.txt` via the Import modal or by dropping files into `inbox/`.

## Getting Started

### Prerequisites
- Node.js (version 18 or higher)

### Quick Start
Double-click `start.bat` or run:
```powershell
node server/index.js
```
Then open your browser at **http://localhost:3000**.

### Running Automated Tests
```powershell
npm.cmd test
```
(or `node --test test/*.test.js`)
